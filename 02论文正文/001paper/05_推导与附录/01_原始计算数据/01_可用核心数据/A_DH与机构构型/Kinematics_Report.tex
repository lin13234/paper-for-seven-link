\section{Modified DH Parameters}
The kinematic structure of the robot is defined by the following Modified DH parameters (Craig's Convention). The transformation matrix $T_i^{i-1}$ is calculated as:
\begin{equation}
T_i^{i-1} = Rot_x(\alpha_{i-1}) Trans_x(a_{i-1}) Rot_z(\theta_i) Trans_z(d_i)
\end{equation}

\section{Fourier Series Trajectory Representation}
For smooth trajectory planning, the joint position $q(t)$ is represented using a finite Fourier series:
\begin{equation}
q(t) = a_0 + \sum_{n=1}^{N} \left( a_n \cos(n\omega_f t) + b_n \sin(n\omega_f t) \right)
\end{equation}
Where:
\begin{itemize}
    \item $a_0$: DC component (average position).
    \item $a_n, b_n$: Fourier coefficients.
    \item $\omega_f$: Fundamental frequency of the motion.
\end{itemize}
