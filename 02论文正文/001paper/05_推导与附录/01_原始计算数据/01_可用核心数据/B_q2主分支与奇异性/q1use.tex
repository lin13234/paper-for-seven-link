\subsection{Fully Substituted Explicit Branch Expression}

For the selected geometric parameters,

\[
l_0=l,\qquad
l_1=l_3=\frac{\sqrt{41}}{2}l,\qquad
l_2=5l,
\]

and

\[
\beta=\operatorname{atan2}(5,4).
\]

Let

\[
\phi=\theta_1-\beta.
\]

Then

\[
d
=
\frac{l}{2}
\sqrt{
45-4\sqrt{41}\cos\phi
}.
\]

The angle $\alpha$ becomes

\[
\alpha
=
\operatorname{atan2}
\left(
\sqrt{41}\sin\phi,\,
\sqrt{41}\cos\phi-2
\right).
\]

The angle $\gamma$ becomes

\[
\gamma
=
\arccos
\left(
\frac{
-7-2\sqrt{41}\cos\phi
}
{
\sqrt{41}
\sqrt{
45-4\sqrt{41}\cos\phi
}
}
\right).
\]

Therefore, the output angle of the selected assembly branch is

\[
\boxed{
\theta_7(\theta_1)
=
\pi
+
\operatorname{atan2}(5,4)
-
\operatorname{atan2}
\left(
\sqrt{41}\sin\phi,\,
\sqrt{41}\cos\phi-2
\right)
+
\arccos
\left(
\frac{
-7-2\sqrt{41}\cos\phi
}
{
\sqrt{41}
\sqrt{
45-4\sqrt{41}\cos\phi
}
}
\right)
}
\]

where

\[
\phi=\theta_1-\operatorname{atan2}(5,4).
\]

Equivalently, after substituting $\phi$ explicitly,

\[
\boxed{
\theta_7(\theta_1)
=
\pi
+
