# 原始计算数据说明

本目录用于集中存放论文《7R 平面对称空间机构》相关的原始运动学计算数据。

## 目录结构

- `01_可用核心数据`
  当前优先用于论文正文作图和写作的数据源。
- `02_待核查结果`
  保留试算版本、异常拟合结果和多分支探索结果，当前不要直接引用到正文。

## 使用原则

1. 正文优先使用 `01_可用核心数据`。
2. `02_待核查结果` 只作回溯和排错参考。
3. 当前论文主线只围绕两种运动模式展开：
   - `q2` 驱动的主空间分支
   - `q1` 驱动的退化平面分支
