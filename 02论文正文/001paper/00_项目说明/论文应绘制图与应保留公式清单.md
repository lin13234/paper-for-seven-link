# 论文应绘制图与应保留公式清单

## 1. 本清单用途

本文件用于单独汇总：

- 本篇论文建议绘制哪些主文图
- 每张图对应什么章节和结论
- 哪些公式建议保留在正文
- 哪些公式建议只放附录

目的不是把所有已有结果都塞进论文，而是围绕主线筛选：

> 7R 平面对称空间机构具有两个单自由度运动分支，并可通过奇异位形实现分支切换；该特性可用于欠驱动移动机器人。

## 3. 正文建议保留的公式

正文保留公式的原则：

- 只保留支撑结论的公式
- 不把所有推导细节都塞进正文

## 公式 1. 闭环方程

### 作用

- 定义 7R 空间闭链机构的闭环约束

### 建议形式

```latex
T_1 T_2 T_3 T_4 T_5 T_6 T_7 = I
```

## 公式 2. 速度约束方程

### 作用

- 引出雅可比矩阵和被动雅可比矩阵

### 建议形式

```latex
J \dot{q} = 0
```

## 公式 3. 主动/被动关节分块方程

### 作用

- 为后续 SVD 分析做准备

### 建议形式

```latex
J_p \dot{q}_p = - J_a \dot{q}_a
```

## 公式 4. 改进 G-K 公式

### 作用

- 给出全局自由度结论

### 建议形式

```latex
M = d(n-g-1) + \sum_{i=1}^{g} f_i
```

如果你正文里同时给出：

- `lambda = 0`
- `d = 6`
- `M = 1`

就足够了。

## 公式 5. 奇异位形判据

### 作用

- 定义被动雅可比秩亏和最小奇异值判据

### 建议写法

```latex
\sigma_{\min}(J_p) \rightarrow 0
```

或者用文字说明：

- 当被动雅可比矩阵的最小奇异值趋于零时，机构达到奇异位形。

## 公式 6. 主分支对称约束关系

### 作用

- 这是正文必须保留的核心公式之一

### 建议形式

```latex
q_7 = q_1, \quad q_6 = -q_2, \quad q_5 = -q_3
```

如果你后面改成 SW/仿真编号为主，这里要统一重写为新的编号体系。

## 公式 7. 退化分支约束关系

### 作用

- 说明第二运动模式下哪些关节锁定，哪些关节主导运动

### 建议形式

正文不一定非得写成很复杂的解析公式，更建议写成约束关系：

```latex
q_i = \text{const.}, \quad q_j = \text{const.}, \quad q_k = \text{const.}
```

再配合图说明剩余关节构成退化平面分支。

## 公式 8. PPO 奖励函数

### 所属章节

- 第 4 章

### 作用

- 这一条很重要，不能只口头描述

### 建议形式

写成分项和：

```latex
r = w_1 r_{\text{forward}} + w_2 r_{\text{stability}} - w_3 r_{\text{energy}} - w_4 r_{\text{penalty}} + \cdots
```

然后用文字说明每一项含义。
