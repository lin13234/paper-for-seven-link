# 七杆闭链机构的 1–3–5–7 平面四杆运动模式设计

## 1. 目标

基于给定的七关节改进 DH 参数，以

\[
\mathbf q_0=[0,0,0,0,0,0,0]
\]

为初始闭环构型，锁定关节 \(2,4,6\)，令关节 \(1,3,5,7\) 形成平面四杆运动。以 \(q_1\) 为输入角，求同一初始装配支路上的

\[
q_3(q_1),\qquad q_5(q_1),\qquad q_7(q_1)
\]

显式解，并绘制角度变化、闭环误差及机构构型图。

## 2. DH 约定

沿用原脚本中的变换矩阵：

\[
{}^{i-1}T_i=
\begin{bmatrix}
\cos\theta_i&-\sin\theta_i&0&a_{i-1}\\
\sin\theta_i\cos\alpha_{i-1}&
\cos\theta_i\cos\alpha_{i-1}&
-\sin\alpha_{i-1}&
-d_i\sin\alpha_{i-1}\\
\sin\theta_i\sin\alpha_{i-1}&
\cos\theta_i\sin\alpha_{i-1}&
\cos\alpha_{i-1}&
d_i\cos\alpha_{i-1}\\
0&0&0&1
\end{bmatrix},
\]

其中

\[
\theta_i=q_i+\theta_{i,\mathrm{offset}}.
\]

该矩阵属于改进 DH 型写法。关节轴不能直接用累计变换前一坐标系的 \(z\) 轴代替，程序将按照固定变换后的实际转轴计算。

## 3. 初始闭环及四杆等效

数值验证表明：

\[
T_1(\mathbf q_0)T_2(\mathbf q_0)\cdots T_7(\mathbf q_0)
=I,
\]

Frobenius 范数误差约为 \(9.87\times10^{-16}\)。

在初始平面中，四根活动关节轴的轴心为

\[
P_1=(1,0),\quad
P_3=(3,-2.5),\quad
P_5=(-2,-2.5),\quad
P_7=(0,0).
\]

对应四杆长度为

\[
L_{13}=L_{57}=\frac{\sqrt{41}}2,\qquad
L_{35}=5,\qquad
L_{71}=1.
\]

关节 \(2,4,6\) 固定为零后，这些长度保持不变。

## 4. 显式位置解

将固定轴心 \(P_7\) 与 \(P_1\) 作为机架两端。输入角 \(q_1\) 决定活动轴心 \(P_3(q_1)\)。轴心 \(P_5\) 同时满足

\[
\|P_5-P_3\|=L_{35},\qquad
\|P_5-P_7\|=L_{57}.
\]

设

\[
\mathbf e=\frac{P_7-P_3}{D},\qquad
\mathbf e_\perp=(-e_y,e_x),\qquad
D=\|P_7-P_3\|,
\]

则两圆交点显式写为

\[
P_5=P_3+x\mathbf e+s\,h\mathbf e_\perp,
\]

其中

\[
x=\frac{L_{35}^2-L_{57}^2+D^2}{2D},
\qquad
h=\sqrt{L_{35}^2-x^2},
\qquad s\in\{-1,+1\}.
\]

程序在 \(q_1=0\) 处比较两个交点与初始 \(P_5=(-2,-2.5)\) 的距离，自动确定符号 \(s\)，并在整个输入区间保持该装配支路。若 \(h^2<0\)，该输入角不可达。

## 5. DH 关节角回映射

由轴心坐标可得到三根活动杆的绝对方向：

\[
\phi_{13}=\operatorname{atan2}(P_{3y}-P_{1y},P_{3x}-P_{1x}),
\]

\[
\phi_{35}=\operatorname{atan2}(P_{5y}-P_{3y},P_{5x}-P_{3x}),
\]

\[
\phi_{57}=\operatorname{atan2}(P_{7y}-P_{5y},P_{7x}-P_{5x}).
\]

不能直接将这些绝对方向当作 \(q_3,q_5,q_7\)。程序将通过初始方向差和关节轴正负方向，把杆件相对转角映射回原七杆 DH 变量。映射后要求 \(q_1=0\) 时：

\[
q_3=q_5=q_7=0.
\]

角度序列使用连续展开，避免 `atan2` 在 \(\pm\pi\) 处产生人为跳变。

## 6. 验证

每个显式解均代回完整七杆闭环：

\[
T_{\mathrm{end}}(q_1,0,q_3,0,q_5,0,q_7)
=T_1T_2\cdots T_7.
\]

分别记录：

\[
e_p=\|\mathbf p_{\mathrm{end}}\|_2,
\]

以及旋转误差

\[
e_R=
\cos^{-1}\left(
\operatorname{clip}
\frac{\operatorname{tr}(R_{\mathrm{end}})-1}{2}
\right).
\]

显式解只有在杆长约束和完整 DH 闭环误差同时满足容差时才标记为有效。

## 7. 图像和输出

Python 脚本输出：

1. \(q_3,q_5,q_7\) 关于输入 \(q_1\) 的连续角度曲线；
2. 完整 DH 闭环的位置误差和姿态误差；
3. 若干典型输入角下的四杆构型；
4. 有效输入区间和死点位置；
5. CSV 数值结果；
6. PNG、SVG、PDF 三种图像格式。

图像采用白色背景、统一低饱和配色，并直接标注关节曲线。主图是关节角映射，误差图和机构构型作为验证证据。

## 8. 边界和异常处理

- 两圆无交点时，将该输入角记为不可达，不强行生成复数解。
- \(D=0\) 或 \(h\approx0\) 时标记为几何退化或死点。
- 若几何闭环成立但完整 DH 闭环不成立，立即报告角度回映射或 DH 约定不一致。
- 不使用多项式或傅里叶拟合作为“显式解”；显式解来自闭环几何方程，拟合只能作为另选的近似表达。
